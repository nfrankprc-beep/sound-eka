# Память проекта sound-eka

Этот файл — долговременная память Claude между сессиями. Каждая новая сессия читает его при старте.
Обновлять в конце каждой задачи: что сделано, какие решения приняты, что дальше.

## О проекте
- Репозиторий: `nfrankprc-beep/sound-eka`.
- Сообщество «АВТОЗВУК Б/У Екатеринбург»: доска объявлений и советы по автозвуку (~16 500 участников).
- `index.html` — одностраничный лендинг/мини-приложение сообщества (тёмная тема, ширина до 480px, без зависимостей).
  - Блок советов «Автозвук на пальцах» рендерится из JS-массива `TIPS` (пары [заголовок, текст]).
  - Кнопка «Перейти в сообщество →»; объявления публикуются через «Предложить новость».

## Как работаем
- Общение с пользователем — на русском.
- Работа идёт в облачных сессиях Claude Code (claude.ai / приложение Claude). Контейнер временный:
  всё важное нужно коммитить и пушить, иначе пропадёт.
- Облачные сессии оплачиваются из «Кредитов облачных сессий» (на 2026-10-10: ~99 $ из 100 $, действуют до 5 ноября 2026, 10:59 МСК).
- Доступа к файлам домашнего ПК у облачной сессии нет. Есть подключённый MCP-сервер `wpsblacktop_com`
  (личный Linux-сервер, файлы в `/srv/personal-mcp`, без root).
- Чтобы что-то «запомнить» — дописать в этот файл и запушить.
